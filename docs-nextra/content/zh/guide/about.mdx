# 关于

Echo UI 由 [leyoonafr](https://github.com/codeacme17) 于 2023 年 10 月发起。它希望让 Web Audio 应用的交互层更易构建，并向开源社区分享可复用的解决方案。

项目仍然年轻，也在持续迭代中。欢迎提交问题、Bug 报告、设计反馈和代码贡献。

## 联系方式

- [提交 GitHub Issue](https://github.com/codeacme17/echo-ui/issues/new)
- [发起 GitHub Discussion](https://github.com/codeacme17/echo-ui/discussions/new/choose)
- [在 X 上关注 leyoonafr](https://twitter.com/codeacme17)
- [发送邮件](mailto:codeacme17@gmail.com)

加入 [Echo UI Discord 服务器](https://discord.gg/R9JX9twvXF)，与其他用户和贡献者交流。
