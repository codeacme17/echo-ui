# Light

`Light` is a compact visual indicator for signal, bypass, recording, and connection states.

<InstallPackage lang="en" />

```tsx
import '@nafr/echo-ui/style.css'
import { Light } from '@nafr/echo-ui'
```

## Live Web Audio example

This indicator is driven by the RMS level of a real `AnalyserNode`, rather than a timer or random placeholder.

<DisplayDemo display="light" lang="en" />

<ComponentVariantMatrix component="light" lang="en" />

## Color and size

```tsx
<div aria-label={connected ? 'Input connected' : 'Input disconnected'}>
  <Light on={connected} size="1rem" color="oklch(70% 0.17 145)" />
</div>
```

Color alone should never carry the state. Pair the light with visible text or an accessible label, and choose a color with sufficient contrast against its surrounding surface.
