# Installation

<Callout type="info">
  The current npm release, **`@nafr/echo-ui@1.0.0`**, declares **React 18.2** and matching React DOM peers. The next release expands that range to **React 18.2 or React 19** with the matching React DOM major. Development and documentation use React `19.2.8`; installed-consumer smoke tests render the built package with React `18.3.1` and `19.2.8`.
</Callout>

## Before you begin

Echo UI `1.0.0` was built and documented with Tailwind CSS `3.3.5`, but its published manifest does not declare a Tailwind peer dependency or compatibility range. The configuration below targets Tailwind CSS 3. Compatibility with later Tailwind majors has not been verified.

<Steps>

### Configure Tailwind CSS 3

Add the published component files to Tailwind's content scan and map Echo UI's semantic tokens in `tailwind.config.js`:

```js filename="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './node_modules/@nafr/echo-ui/dist/**/*.{js,cjs,mjs}',
  ],
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        input: 'var(--echo-input)',
        background: 'var(--echo-background)',
        foreground: 'var(--echo-foreground)',
        border: {
          DEFAULT: 'var(--echo-border)',
          foreground: 'var(--echo-border-foreground)',
        },
        button: {
          DEFAULT: 'var(--echo-button)',
          foreground: 'var(--echo-button-foreground)',
        },
        primary: {
          DEFAULT: 'var(--echo-primary)',
          foreground: 'var(--echo-primary-foreground)',
        },
        secondary: {
          DEFAULT: 'var(--echo-secondary)',
          foreground: 'var(--echo-secondary-foreground)',
        },
        muted: {
          DEFAULT: 'var(--echo-muted)',
          foreground: 'var(--echo-muted-foreground)',
        },
        accent: {
          DEFAULT: 'var(--echo-accent)',
          foreground: 'var(--echo-accent-foreground)',
        },
        card: {
          DEFAULT: 'var(--echo-card)',
          foreground: 'var(--echo-card-foreground)',
        },
      },
      borderRadius: {
        lg: 'var(--echo-radius)',
        md: 'calc(var(--echo-radius) - 2px)',
        sm: 'calc(var(--echo-radius) - 4px)',
      },
    },
  },
}
```

### Add the theme variables

Include Tailwind's layers and the Echo UI tokens in your main stylesheet. The values below match the published documentation theme and can be customized.

```css filename="src/index.css"
@tailwind base;
@tailwind components;
@tailwind utilities;

  --echo-background: #f1efef;
  --echo-foreground: #181818;
  --echo-card: #dadada;
  --echo-card-foreground: #2a2a2a;
  --echo-primary: #ffaa01;
  --echo-primary-foreground: #e49c0c;
  --echo-secondary: #f3b945;
  --echo-secondary-foreground: #b7944e;
  --echo-muted: #c4c4c4;
  --echo-muted-foreground: #393939;
  --echo-accent: #f4f4f5;
```
