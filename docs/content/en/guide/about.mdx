# About

Echo UI was started by [leyoonafr](https://github.com/codeacme17) in October 2023. It began as an attempt to make the interaction layer of Web Audio applications more approachable and to share reusable solutions with the open-source community.

The project is still young and continues to evolve. Questions, bug reports, design feedback, and contributions are all welcome.
